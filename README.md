Rimworld Mod

Workshop URL: https://steamcommunity.com/sharedfiles/filedetails/?id=3711652575

如何安装：选择右上角绿色按钮<>Code，选择Download ZIP，将解压后的模组放入Rimworld游戏本体文件夹下的Mods文件夹。


增加了一些实用物品和功能的自用小模组。
v1.7.0

超锻合金：一种美观的合金，用作利器或防具也表现良好。
红相晶钢：一种好看的合金兼石材，用作建筑或钝器表现良好。
青相合金：兼顾美观与性能的合金兼石材，多种性能均表现优异。
星狐织物：狐狐们在星际时代的通用民用织物，数值是脚填的。
敲击兽毛：由敲击兽产出的一种超级毛料，但作为原料存放时很容易坏。
塑料布：从有毒垃圾中提取的廉价回收塑料，没有防护和隔热但超耐用。

天界：高射速高伤害高穿甲的强力远程武器。
NSV：体验塔科夫同款重机枪，即使在边缘世界也能体验被储备站重机枪架着的感觉了。
Mk-18：一把大威力远距离精确射手步枪。
AXMC：一把大威力远距离栓动狙击步枪。
HK416 MODIII：404小队定制的HK416。
HK416A5：HK416突击步枪的现代化改进型。
HK416C：HK416A5的另一个版本。
HKUSP45：一把比原版自动手枪稍好的速射手枪，可以自己搓。

添加了一些原版中无法制作或难以获取的物品配方。

让阿敲也能作为驮运和骑乘动物了。

3把作弊武器：IKARUS、SV_StarVulpes_556AssaultRifle、SV_StarVulpes_338_Rifle，战斗打红温了就戴上绿色雪牛面具拿，就是不能无视承伤。
